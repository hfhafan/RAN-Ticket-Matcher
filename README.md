# RAN Ticket Matcher

RAN Ticket Matcher adalah aplikasi Windows untuk mencocokkan daftar Site ID dengan RAN Cell Report, Incident Ticket, dan Current Alarm. Aplikasi ini dibuat agar tim operasional bisa melihat alarm aktif, kandidat NE, dan status ticket dalam satu file Excel yang rapi.

## Tujuan

- Mempercepat pengecekan Site ID tanpa lookup manual berulang.
- Menjaga semua kandidat NE untuk Site ID yang memiliki lebih dari satu NE.
- Membantu melihat current alarm yang sudah atau belum memiliki ticket.
- Menghasilkan workbook Excel yang siap dipakai untuk follow up operasional.

## Ringkas Cara Kerja

1. Masukkan daftar Site ID.
2. Pilih folder RAN Cell Report.
3. Pilih file atau folder Incident Ticket.
4. Masukkan URL CSV atau file lokal Current Alarm.
5. Jalankan matcher dan baca output Excel.
